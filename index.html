01 / DEV · ЧТО НУЖНО

Довести скрипт до одной команды

  • Свой GitHub и Python или JavaScript на уровне «запускается и проверяется».
  • Умеешь описать запуск так, чтобы другой человек повторил его без созвона.
  • Не сдаёшь черновик, который работает только на твоей машине.

БЕЙДЖ

  • README
  • Одна команда
  • Запуск с первого раза

Бейдж, если команда из README запускается с первого раза и даёт таблицу результата.

02 / OPS · ЧТО НУЖНО

Цифра без источника не считается

  • Собираешь таблицу: факт, источник, дата проверки, контакт.
  • Расхождения помечаешь, а не усредняешь.
  • Не выдумываешь время, цены и имена.

  • Дата проверки
  • Совпадение цифры

03 / MARKET · ЧТО НУЖНО

Прямой текст, который можно отправить

  • Пишешь коротко, живым языком, без канцелярита.
  • В тексте есть просьба, дата и способ ответа.
  • Есть развилка: «если не твоё — кого посоветуешь?».

БЕЙДЖ

  • Прямой запрос
  • Без давления
  • Список каналов
